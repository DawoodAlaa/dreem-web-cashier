# كاشير الموبايلات — نسخة الموقع

موقع (PWA) بيشتغل على نفس سيرفر Supabase الحالي بنفس الحسابات والبيانات. مبني بـ React + Vite + TypeScript + Tailwind.

## التشغيل على الجهاز

```bash
npm install
npm run dev
```

بعدها افتح http://localhost:5173

## البناء والرفع

```bash
npm run build
```

الرفع على GitHub Pages: `npm run deploy` (بيبني وبيرفع على فرع gh-pages).

أو ارفع فولدر `dist` على Vercel أو Netlify أو Cloudflare Pages (أمر البناء `npm run build` وفولدر النشر `dist`).
الموقع بيستخدم روابط `#/` فمش محتاج أي إعدادات إضافية على الاستضافة.

## على الآيفون

افتح الموقع في Safari ← زرار المشاركة ← "إضافة إلى الشاشة الرئيسية". هيفتح زي التطبيق من غير شريط المتصفح.

## حفظ بيانات الدخول

- **افتكرني على الجهاز ده**: الجلسة بتتحفظ، فلما تفتح الموقع تاني تدخل على طول من غير تسجيل دخول.
- **احفظ اسم المستخدم والباسورد**: لو سجلت خروج، الحساب بيظهر في "دخول سريع" وتدخل بضغطة.
  الباسورد بيتحفظ على الجهاز ده بس (مش نص عادي)، وتقدر تمسحه بزرار السلة جنب الحساب.
- الخانات معمولة بحيث الآيفون (iCloud Keychain) يعرض يحفظ الباسورد كمان.

## ملفات مهمة

- `src/lib/supabase.ts` الاتصال بالسيرفر + حفظ الجلسة
- `src/lib/savedAccounts.ts` الحسابات المحفوظة على الجهاز
- `src/lib/shop.ts` المنتجات في الذاكرة + التحديث اللحظي
- `src/lib/cart.ts` السلة وتوزيع سعر العروض
- `src/pages/*` الشاشات
