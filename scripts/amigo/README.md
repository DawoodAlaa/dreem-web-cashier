# استيراد توفيقات الاسكرينات من كتالوج Amigo

اتعمل أول مرة يوم 2026-10-19: 333 منتج (191 حواف 0.4 + 142 برايفسي 0.3) و 333 توفيقة.

لتحديث الكتالوج (الأكواد الجديدة بس هتتضاف، والموجود بيتساب زي ما هو):

```bash
node scripts/amigo/fetch-all.mjs   # بيجيب الكتالوج كله ← all.json
node scripts/amigo/build.mjs       # بيجهز البيانات ← import-data.json
```

بعدها `import-data.json` بيتحط في سكريبت الاستيراد في SQL Editor على Supabase (نفس السكريبت اللي اتنفذ أول مرة:
بيستخدم quick_add كصاحب المحل للمنتجات، وبيربط كل منتج بأجهزته في compat_groups / compat_devices).
الأسعار: حواف 0.4 = جملة 15 / بيع 50 / أقل 30، برايفسي = جملة 20 / بيع 50 / أقل 30.
